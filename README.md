# KarginTech

Сервис для поставщиков по торгам 44-ФЗ и 223-ФЗ: находит закупки в ЕИС,
читает документацию и ТЗ кодом, извлекает позиции и условия, ищет реальные
закупочные цены, считает экономику участия и формирует Excel-смету.
Есть сайт с кабинетами клиента и владельца, оплата и загрузка документов.

## Технологии

- Node.js 22, CommonJS, **без внешних npm-зависимостей**
- SQLite (`node:sqlite`) — сайт и состояние; PostgreSQL 16 — для n8n
- Python 3 + OpenCV/NumPy — разбор таблиц и сканов
- n8n — расписания, webhook, уведомления
- Docker Compose (7 контейнеров) + Caddy

## Структура

| Каталог | Содержимое |
|---|---|
| `src/` | Чистая предметная логика: парсеры ЕИС, чтение документов, фильтры, цены, единицы, XLSX, самопроверка |
| `app/` | HTTP и оркестрация: главный расчёт (`estimate-run.js`), поток, архив, поиск поставщиков |
| `site/` | Собственный HTTP-сервер: страницы, аутентификация, кабинеты, оплата |
| `n8n/` | Пять воркфлоу автоматизации (JSON) и их проверка |
| `deploy/` | Docker Compose, Caddy, скрипты установки, проверки и резервных копий |
| `tests/` | Наборы проверок (JS) и Python-проверка разбора таблиц |
| `fixtures/` | Сохранённые реальные страницы портала для тестов |

Основной поток: ЕИС или загрузка → документы → код/OCR → позиции и ТЗ →
локальный прайс/каталоги/поиск → независимая сверка → расчёт и XLSX.

## Проверки

```bash
npm test                        # основной набор
node tests/run-tests.js         # общий прогон
node tests/test-pricing.js      # точечный набор для изменённой области
python -I tests/test_borderless.py
```

`npm test` не включает все наборы `tests/test-*.js` — при изменении логики
запускайте затронутые наборы отдельно и смотрите итог
`ВСЕ ПРОВЕРКИ ПРОЙДЕНЫ`.

## Развёртывание

Сервер: Ubuntu 24.04, Docker. Состав контейнеров и настройки —
`deploy/docker-compose.yml`, скрипт первой установки — `deploy/setup-server.sh`,
проверка конвертера — `deploy/check-converter.sh`, резервные копии —
`deploy/backup.sh`.

## Принципы проекта

- Документы читает код; модель — только для того, чего код не умеет.
- Ничего не выдумывать: нет данных — нет числа, цена без источника не идёт
  в расчёт.
- Клиентские данные не покидают контур сервера; изоляция по `company_id`.
