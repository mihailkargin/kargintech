# Сюда кладутся корневые сертификаты НУЦ Минцифры

Папка заполняется автоматически скриптом `deploy/setup-server.sh` (шаг 3).
Сам он скачивает два файла с официального сайта Госуслуг и проверяет, что
это действительно сертификаты, а не страница с ошибкой.

**Если папка пуста, сборка образа упадёт** с сообщением про отсутствующий
путь `deploy/certs/`. Это не поломка, а напоминание: сначала `setup-server.sh`,
потом `docker compose build`.

**Зачем это нужно.** Сертификат портала закупок выпущен удостоверяющим
центром Минцифры. В стандартном наборе доверенных корней его нет, поэтому
на чистом сервере любой запрос к порталу падает с ошибкой недоверия.

**Почему файлы не скачиваются во время сборки образа.** Тогда недоступность
стороннего сайта роняла бы сборку целиком, а подменённый файл попал бы
в доверенные корни незамеченным. Так их можно посмотреть глазами до того,
как сервер начнёт им доверять:

```
openssl x509 -in russian_trusted_root_ca.crt -noout -subject -dates
```

**Если скачать не удалось** — актуальные ссылки лежат на
https://www.gosuslugi.ru/crt, файлы положить сюда вручную под теми же
именами: `russian_trusted_root_ca.crt` и `russian_trusted_sub_ca.crt`.
